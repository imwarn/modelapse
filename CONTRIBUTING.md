# Contributing to Modelapse

The project is in foundation stage. Prefer changes that preserve auditability and make future providers/tests easier to add.

## Community test proposals

Include the canonical source, original author, earliest known publication date, verbatim prompt, fixtures, redistributable artifacts if available, claimed model/provider/execution path, rights status, and whether the test can support a shadow suite.

A screenshot is not verified API output. Modelapse keeps community evidence distinct from Modelapse-controlled execution.

Architecture changes to provenance, Test Pack semantics, immutable runs/artifacts, or model-lineage relations should include an ADR.
